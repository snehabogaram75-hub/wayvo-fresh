# 🚀 WAYVO – Your Personal AI Assistant

**WAYVO** is an AI-powered personal assistant designed to bring multiple intelligent tools and everyday productivity features into one application.

Built with Flutter and Python Flask, WAYVO combines AI conversations, voice interaction, document intelligence, learning tools, web search and more — all in one place.

## ✨ Features

### 🤖 AI Assistant
- AI-powered conversations with streaming responses.
- Supports English, Telugu and Tanglish.
- Voice interaction.
- Live web search.

### 📚 Learning & Productivity
- AI Tutor and Study Buddy.
- Automatic quiz generation.
- Flashcard generation.
- Interview preparation and coaching.
- AI Code Helper.
- Document Helper.

### 📄 Document Intelligence
- Upload documents and ask questions.
- RAG-based document retrieval and question answering.
- Semantic search using MongoDB Atlas Vector Search.
- Context-aware responses using retrieved document information.
- Keyword-based fallback retrieval.

### 🌱 Additional AI Tools
- Plant Copilot.
- Shop Helper.
- AI Image Generation.
- Personal Diary and Library.
- One-time photo and file sharing.

### 🔐 Privacy & Security
- Biometric chat lock.
- PIN-based security.
- Chat archive functionality.

## 🏗️ Project Architecture

WAYVO follows a Flutter frontend and Flask backend architecture.

- **Flutter:** Provides the mobile application interface.
- **Flask:** Handles backend APIs and application logic.
- **Supabase:** Supports relational data storage.
- **MongoDB Atlas:** Supports vector storage and semantic document retrieval.
- **AI Services:** Power conversations, document understanding and other intelligent features.

## 💻 Run Locally

### Prerequisites
- Flutter SDK
- Python
- Git
- Required API credentials and database configurations

### Clone the Repository

```bash
git clone https://github.com/snehabogaram75-hub/wayvo-fresh.git
cd wayvo-fresh
```

### Backend Setup

```bash
pip install -r requirements.txt
python app.py
```

Configure the required API keys and database credentials using the environment configuration expected by the backend.

### Flutter Setup

```bash
cd wayvo
flutter pub get
flutter run
```
